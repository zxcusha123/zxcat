# CV Лабораторная работа — Майер Арсений

Персональное резюме с настроенным CI/CD пайплайном через GitHub Actions и деплоем на GitHub Pages.

## О проекте
Здесь собрано мое портфолио и академический опыт. Я студент СПбПУ (Математическое обеспечение и администрирование ИС), фокусируюсь на низкоуровневой разработке на C/C++, работе с памятью и алгоритмами.

В качестве нестандартного элемента (пасхалки) реализован ZXC-режим (цикличный переключатель темы), который меняет стили сайта на ч\б вариант с красноватыми ссылками, применяет кастомный шрифт (UnquietSpirits) к заголовкам и добавляет гифку zxc-кота.
